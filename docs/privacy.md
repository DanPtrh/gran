# Политика конфиденциальности

**Приложение:** ГРАНЬ (`app.gran.mobile`)
**Дата вступления в силу:** 3 июня 2026 года
**Последнее обновление:** 3 июня 2026 года

## Кратко

ГРАНЬ хранит все данные пользователя локально на его устройстве. У приложения нет аккаунта, регистрации, рекламных идентификаторов, аналитики и трекинга. В фоне приложение данные не собирает и по умолчанию работает офлайн.

Единственное исключение — **форма обратной связи**: если пользователь сам решит написать автору и нажмёт «отправить», введённый им текст (и, по желанию, email для ответа) передаётся через сторонний сервис доставки писем. Это происходит только по явному действию пользователя и только с тем, что он сам ввёл в форму. Подробнее — в разделе 3.

## 1. Кто отвечает за обработку

Разработчик и оператор приложения — физическое лицо, контакты для связи: `app.gransup@gmail.com`.

Данные, которые пользователь создаёт в приложении, хранятся исключительно на его устройстве и разработчику не передаются. Единственное исключение — добровольное обращение через форму обратной связи (раздел 3): отправляя его, пользователь сам передаёт разработчику введённый текст и, по желанию, email для ответа. В этом объёме и только при явной отправке разработчик выступает оператором обработки персональных данных в смысле Федерального закона №152-ФЗ «О персональных данных» и использует полученные данные исключительно для ответа пользователю.

## 2. Какие данные хранятся локально

В защищённом локальном хранилище приложения (Android AsyncStorage, изолированном на уровне ОС от других приложений) сохраняются:

- **Имя аватара** — текст, который пользователь вводит при создании профиля. Может быть любым набором символов, включая псевдоним. Не верифицируется и не сверяется с реальным именем.
- **Выбранный навык и прогресс** — какие задания выполнены, текущий уровень, даты выполнения, использованные переносы.
- **Тексты рефлексии** — ответы пользователя на два вопроса после каждого выполненного задания («что было сложным» и «что удивило»).
- **Оценка дискомфорта** — число от 1 до 5, проставленное пользователем после задания.

Все перечисленные данные пользователь создаёт сам. Приложение не собирает идентификаторы устройства (IMEI, рекламный ID, MAC-адрес), не записывает геолокацию, не использует камеру, микрофон, контакты или календарь.

**Уведомления.** Если пользователь включит ежедневное напоминание в настройках, приложение запросит разрешение на показ уведомлений и будет планировать их локально на устройстве средствами операционной системы. Текст напоминания фиксирован и не зависит от данных пользователя; для показа уведомлений никакая информация наружу не передаётся. Разрешение можно отозвать в системных настройках Android в любой момент — тогда напоминания просто перестанут приходить.

## 3. Передача данных третьим лицам

Приложение не имеет встроенной аналитики, SDK сторонних сервисов, рекламных сетей или crash-репортинга. В обычном режиме использования (выполнение заданий, рефлексия, журнал) никакие данные с устройства не отправляются — всё хранится локально.

**Форма обратной связи.** В разделе «Настройки → Связь» есть форма, через которую пользователь по собственному желанию может написать автору. Если пользователь заполнит её и нажмёт «отправить», на сервер передаётся:

- **текст обращения**, который пользователь ввёл сам;
- **email для ответа** — только если пользователь указал его (поле необязательное);
- **имя аватара**, **версия приложения** и **платформа** (Android) — чтобы автор понимал контекст обращения.

Эти данные уходят на промежуточный сервис автора, который пересылает их письмом на почту разработчика через сторонний сервис доставки электронной почты (Resend, resend.com). Серверы этих сервисов могут располагаться за пределами Российской Федерации. Обращение хранится только в виде полученного автором письма и используется исключительно для ответа пользователю и улучшения приложения; третьим лицам в иных целях оно не передаётся.

Передача происходит **только по явной инициативе пользователя** — при нажатии кнопки «отправить». Если пользователь не пользуется формой обратной связи, никакие данные с устройства не покидают его. Чтобы получить ответ, достаточно текста обращения; email указывать не обязательно.

**Будущая синхронизация.** В будущих версиях планируется опциональная синхронизация данных между устройствами одного пользователя. На момент её добавления политика будет обновлена, и пользователь сможет ознакомиться с условиями до того, как авторизоваться. Без явной авторизации синхронизация работать не будет.

## 4. Сроки хранения

Данные хранятся до того момента, пока пользователь не удалит их одним из способов:

- В приложении: **Настройки → Опасная зона → Удалить аватара**. Эта операция стирает все данные ГРАНИ с устройства и не может быть отменена.
- Удаление приложения через настройки Android — Android при удалении приложения автоматически очищает его локальное хранилище.

После удаления данные не подлежат восстановлению.

## 5. Права пользователя

Данные приложения хранятся локально на устройстве, поэтому пользователь сам полностью контролирует их: создаёт, изменяет, удаляет в любой момент через интерфейс приложения. Запрос на удаление направлять разработчику не требуется — это делается одним действием в приложении.

Если пользователь отправлял обращение через форму обратной связи и хочет, чтобы разработчик удалил полученное письмо с его текстом и email, достаточно написать об этом на `app.gransup@gmail.com` — обращение будет удалено. Туда же можно направить любые вопросы об обработке данных.

## 6. Дети

Приложение не предназначено для детей младше 12 лет. ГРАНЬ не собирает осознанно данные о пользователях младше 12 лет. Если родителю стало известно, что ребёнок младше указанного возраста использует приложение, рекомендуется удалить приложение или очистить данные через настройки.

## 7. Безопасность

Данные приложения хранятся в стандартном защищённом хранилище Android (Android Application Sandbox), доступ к которому изолирован на уровне операционной системы. К этому локальному хранилищу разработчик доступа не имеет.

Поскольку в обычном режиме приложение не передаёт данные по сети, связанные с этим риски отсутствуют. При отправке обращения через форму обратной связи передача выполняется по защищённому протоколу HTTPS; пользователь сам решает, отправлять ли обращение и указывать ли в нём email.

## 8. Изменения политики

Политика может обновляться по мере развития приложения. Актуальная редакция всегда доступна по адресу, указанному в карточке приложения в RuStore и Google Play. Дата последнего обновления указана в начале документа.

В случае существенных изменений (например, при добавлении синхронизации с сервером) пользователь будет уведомлён внутри приложения и будет иметь возможность ознакомиться с новой редакцией до того, как продолжить пользоваться функцией.
