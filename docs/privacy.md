# Политика конфиденциальности

**Приложение:** ГРАНЬ (`app.gran.mobile`)
**Дата вступления в силу:** 18 мая 2026 года
**Последнее обновление:** 18 мая 2026 года

## Кратко

ГРАНЬ хранит все данные пользователя локально на его устройстве. Никакая информация не передаётся на сервер автора, в аналитические системы или третьим лицам. У приложения нет собственного аккаунта пользователя, регистрации, идентификаторов, аналитики и трекинга.

## 1. Кто отвечает за обработку

Разработчик и оператор приложения — физическое лицо, контакты для связи: `app.gransup@gmail.com`.

Поскольку приложение не передаёт данные пользователя на серверы разработчика, обработка персональных данных, попадающих под Федеральный закон №152-ФЗ «О персональных данных», по сути не производится. Все данные, которые пользователь создаёт в приложении, хранятся исключительно на его устройстве.

## 2. Какие данные хранятся локально

В защищённом локальном хранилище приложения (Android AsyncStorage, изолированном на уровне ОС от других приложений) сохраняются:

- **Имя аватара** — текст, который пользователь вводит при создании профиля. Может быть любым набором символов, включая псевдоним. Не верифицируется и не сверяется с реальным именем.
- **Выбранный навык и прогресс** — какие задания выполнены, текущий уровень, даты выполнения, использованные переносы.
- **Тексты рефлексии** — ответы пользователя на два вопроса после каждого выполненного задания («что было сложным» и «что удивило»).
- **Оценка дискомфорта** — число от 1 до 5, проставленное пользователем после задания.

Все перечисленные данные пользователь создаёт сам. Приложение не собирает идентификаторы устройства (IMEI, рекламный ID, MAC-адрес), не записывает геолокацию, не использует камеру, микрофон, контакты, календарь или другие системные ресурсы.

## 3. Передача данных третьим лицам

Не производится. Приложение работает полностью офлайн, не имеет встроенной аналитики, SDK сторонних сервисов, рекламных сетей или crash-репортинга.

В будущих версиях планируется опциональная синхронизация данных между устройствами одного пользователя. На момент её добавления политика будет обновлена, и пользователь сможет ознакомиться с условиями до того, как авторизоваться. Без явной авторизации синхронизация работать не будет.

## 4. Сроки хранения

Данные хранятся до того момента, пока пользователь не удалит их одним из способов:

- В приложении: **Настройки → Опасная зона → Удалить аватара**. Эта операция стирает все данные ГРАНИ с устройства и не может быть отменена.
- Удаление приложения через настройки Android — Android при удалении приложения автоматически очищает его локальное хранилище.

После удаления данные не подлежат восстановлению.

## 5. Права пользователя

Поскольку данные хранятся локально на устройстве и не передаются разработчику, пользователь сам полностью контролирует их: создаёт, изменяет, удаляет в любой момент через интерфейс приложения. Запрос на удаление данных направлять разработчику не требуется — это делается одним действием в приложении.

Если у пользователя есть вопросы или сомнения относительно обработки данных, можно написать на `app.gransup@gmail.com`.

## 6. Дети

Приложение не предназначено для детей младше 12 лет. ГРАНЬ не собирает осознанно данные о пользователях младше 12 лет. Если родителю стало известно, что ребёнок младше указанного возраста использует приложение, рекомендуется удалить приложение или очистить данные через настройки.

## 7. Безопасность

Данные хранятся в стандартном защищённом хранилище приложения Android (Android Application Sandbox), доступ к которому изолирован на уровне операционной системы. Разработчик не имеет доступа к этим данным.

Поскольку синхронизация не используется, риски, связанные с передачей данных по сети, отсутствуют.

## 8. Изменения политики

Политика может обновляться по мере развития приложения. Актуальная редакция всегда доступна по адресу, указанному в карточке приложения в RuStore и Google Play. Дата последнего обновления указана в начале документа.

В случае существенных изменений (например, при добавлении синхронизации с сервером) пользователь будет уведомлён внутри приложения и будет иметь возможность ознакомиться с новой редакцией до того, как продолжить пользоваться функцией.

## 9. Применимое право

Документ составлен в соответствии с Федеральным законом №152-ФЗ «О персональных данных» Российской Федерации, а также с учётом требований Google Play Developer Program Policies. Споры, связанные с приложением, регулируются законодательством Российской Федерации.

## 10. Контакты

По всем вопросам, связанным с этой политикой, обработкой данных или работой приложения — пишите на `app.gransup@gmail.com`. Разработчик отвечает в разумные сроки (обычно несколько рабочих дней).
