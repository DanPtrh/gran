# Описания для маркетов

Этот файл — справочник копи для админок RuStore и Google Play. Не публичная страница, не размещается на GitHub Pages. Использовать как источник для копирования в Console.

## Название

**Видимое имя:** Грань
**Транслит (если потребуется):** Gran
**Bundle ID:** `app.gran.mobile`

## Категория

- **Google Play:** Health & Fitness → Self-improvement (или Lifestyle если категории self-improvement нет)
- **RuStore:** Здоровье и фитнес → Саморазвитие

## Возрастной рейтинг

**12+** (Pre-Teen / Подростки).

Обоснование для IARC-анкеты и RuStore:
- Нет насилия, секса, азартных игр, рекламы, покупок.
- Нет UGC-функций с публичной видимостью (комментариев, лент, форумов).
- Есть текстовые поля для личных заметок — закрытые, видны только пользователю.
- Тематика связана с работой над собой, психологическим дискомфортом, общением с незнакомыми людьми — подходит для подростков от 12 лет.

## Полное описание (≤ 4000 символов)

```
ГРАНЬ — приложение, которое помогает менять себя через действие, а не через
чтение очередной статьи о саморазвитии.

Выбираешь один из трёх навыков:
— Общительность: учишься заговаривать первым, держать паузу, отказываться.
— Фокус: тренируешь внимание, замечаешь, как ум уводит в сторону.
— Дисциплина: возвращаешь себя к делу, когда срываешься.

Получаешь по одному заданию в день. Уровни сложности нарастают: от
маленьких шагов («скажи продавцу спасибо, глядя в глаза») до настоящего
дискомфорта («попроси у незнакомца скидку без причины»). После каждого
задания — короткая рефлексия: что было сложным, что удивило, как ты себя
чувствовал.

Метафора — огранка камня. Каждое выполненное задание — это удар по грани.
Постепенно ты огранён действиями, а не словами.

Что внутри:
— Три ветки развития, между которыми можно переключаться. Прогресс
сохраняется, можно возвращаться.
— 75 заданий, написанных с опорой на CBT-экспозицию, ACT и практики
осознанности.
— Эволюционирующий визуальный орб, который растёт вместе с уровнем.
— Журнал всех рефлексий — можно перечитать и увидеть динамику.
— Один перенос задания в долгий путь — не больше, чтобы не превращалось
в откладывание.

Чего внутри нет:
— Лидербордов, бейджей, очков опыта. Это не игра.
— Уведомлений «не забывай!» и push-давления. Открыл — поработал; не
открыл — пропустил день. Без вины.
— Социальных функций, ленты, комментариев. Это глубоко личная работа.
— Подписок, платных уровней, премиума. Приложение полностью бесплатное.
— Аккаунта, регистрации, сбора данных. Всё хранится локально на твоём
устройстве.

Важно: ГРАНЬ — не медицинское приложение и не замена психотерапии.
Если ты проходишь лечение, столкнулся с тревожным или депрессивным
состоянием — посоветуйся со своим специалистом перед использованием.

Возраст: 12+.

Политика конфиденциальности и условия использования:
https://danptrh.github.io/gran

Обратная связь:
app.gransup@gmail.com
```

## Скриншоты (план — снять перед релизом)

Минимум 4, рекомендуется 6–8. Размер: 1080×1920 или больше, портрет. Каждый
с короткой подписью внизу или сверху на янтарном акценте:

1. **Дашборд с заданием дня** — подпись: «Одно задание в день. Без давления.»
2. **TaskDetail (карточка задания)** — подпись: «Маленький шаг или серьёзный
   вызов — ты сам решаешь.»
3. **Reflection (рефлексия)** — подпись: «Каждое действие — повод посмотреть
   на себя честно.»
4. **PathStones / ProgressOrb** — подпись: «Путь из пяти граней. Каждая —
   обработана твоим действием.»
5. **Profile с тремя ветками** — подпись: «Три навыка. Развивай тот, что
   важен сейчас.»
6. **JournalEntry (запись журнала)** — подпись: «Журнал помнит то, что
   забываешь ты.»

Стиль: тёмный фон `#0A0A0F`, янтарный акцент `#C8923A`, шрифты Fraunces +
JetBrains Mono. См. дизайн-конвенции в CLAUDE.md.
